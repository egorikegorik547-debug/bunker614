# 🔊 Звуки игры — почему пропадали и как это исправлено

## Почему звуки пропадали после обновления в другом чате

1. **В репозитории `bunkerex` не было ни одного аудиофайла.** Там лежал только код (`src/game/*.ts`).
   Папки `src/game/sounds/` и `src/game/shots/` существовали *только* в рабочей среде того чата, где игру
   собирали, и при загрузке на GitHub не попали (аудио — бинарные файлы, они в чат-проект «приезжают» отдельно
   от кода).
2. **Код ссылался на эти файлы напрямую** (`import './shots/pistol1.mp3'`,
   `import.meta.glob('./sounds/*.mp3')`). Новый чат получает *только текст кода*, а проект собирает с нуля —
   файлов нет, и:
   * `glob` для `./sounds/*.mp3` молча возвращал пустой список → не играла перезарядка;
   * выстрелы с `./shots/*.mp3` либо ломали сборку, либо (после «исправления» в чате) просто выкидывались.
3. **Ошибки загрузки глотались** (`.catch(() => {})`), а синтезированный запасной звук был удалён —
   поэтому вместо ошибки получалась просто тишина.
4. Оригинальные `gg4` / `sound` — это *длинные* записи. Нарезанные одиночные выстрелы (`pistol1`, `rifle3`…)
   нигде, кроме того чата, не хранились.

## Что сделано

Звук теперь **защищён 5 уровнями** (`src/game/audio/soundBank.ts`), каждый следующий включается,
если предыдущий не сработал:

| # | Уровень | Где лежит | Нужна сеть/файлы? |
|---|---------|-----------|-------------------|
| 1 | **Вшито в код** (base64) | `src/game/audio/embedded/*.ts` | нет — это обычный код |
| 2 | Рабочие файлы | `public/sounds/{shots,reload}/` | файлы на сервере |
| 3 | **Резервные файлы** | `public/sounds-backup/{shots,reload}/` | файлы на сервере |
| 4 | Оригиналы из GitHub (с нарезкой «на лету») | репозитории `gg4`, `sound` через jsDelivr/raw | интернет |
| 5 | Аварийный синтез | `weaponAudio.ts` (`synthShot`, `synthEvent`) | нет |

* Игра остаётся одним файлом `dist/index.html` — звуки внутри него (уровень 1), отдельные файлы не нужны.
* Ничего не падает молча: итог загрузки пишется в консоль браузера (`[звуки] загружено 23/23 …`),
  а полный отчёт — `window.__soundReport()`.
* Список всех звуков и откуда они взяты (включая точки нарезки) — `src/game/audio/manifest.ts`.

## ⚠ Правила при обновлении игры (через любой чат)

**Не удалять и не переписывать:**
```
src/game/audio/            ← загрузчик, манифест, вшитые звуки
public/sounds/             ← рабочие файлы
public/sounds-backup/      ← резерв
scripts/                   ← build-audio-data.mjs, check-sounds.mjs
src/game/weaponAudio.ts    ← можно менять логику, но звуки брать через getBuffer() из ./audio/soundBank
```

Если вы просите другой чат обновить игру, **скопируйте ему этот текст**:

> В проекте есть защищённая звуковая система. Папки `src/game/audio/`, `public/sounds/`,
> `public/sounds-backup/` и `scripts/` НЕЛЬЗЯ удалять, переименовывать или пересоздавать.
> Не заменяй `weaponAudio.ts` целиком и не возвращай `import './shots/*.mp3'`. Звуки подключаются только
> через `getBuffer('ключ')` из `src/game/audio/soundBank.ts`. Новые звуки добавляй в `manifest.ts`.
> После правок выполни `node scripts/check-sounds.mjs` — он должен написать «✓ Все звуки на месте».

## Загрузка на GitHub

Обязательно загружайте **папки целиком** (`public/`, `src/game/audio/`, `scripts/`). Веб-интерфейс
GitHub при перетаскивании иногда пропускает вложенные папки — после загрузки проверьте, что
`public/sounds-backup/shots/pistol1.mp3` и `src/game/audio/embedded/` видны в репозитории.
Лучше всего — загрузить через `git push` или распаковать ZIP целиком.

## Обслуживание

```bash
node scripts/check-sounds.mjs          # проверка: рабочие + резерв + вшитые в код
node scripts/check-sounds.mjs --fix    # восстановить недостающее из резерва / из вшитых данных
node scripts/build-audio-data.mjs      # пересобрать вшитые звуки после замены файла в sounds-backup
```

Замена звука: положите новый файл с тем же именем в `public/sounds-backup/<папка>/`, скопируйте его
в `public/sounds/<папка>/`, выполните `node scripts/build-audio-data.mjs`.
